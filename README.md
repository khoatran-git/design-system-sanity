# Sanity Studio - Group Design System

Visual editor for managing component documentation, foundations, and resources.

## Getting Started

### Install dependencies
```bash
npm install
```

### Run the studio
```bash
npm run dev
```

Opens at `http://localhost:3333`

### Deploy to Sanity
```bash
npm run deploy
```

Studio will be available at: `https://q8ijpuq2.sanity.studio`

## Content Types

### Components
- Component documentation with overview, specs, and examples
- Props and usage examples
- Related components linking

### Foundations
- Design system guidelines (typography, colors, motion, etc.)
- Rich content with images and code blocks
- Custom color palettes and typography scales

### Resources
- Links, documents, tools, and guides
- External resource management
- Custom ordering and categorization
